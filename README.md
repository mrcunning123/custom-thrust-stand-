Hi everyone,

This project is a thrust test stand designed for a high-pressure water rocket. The rocket engine itself will be custom-built, but that will be covered separately in another project.

You can find detailed notes and progress updates in journal.md, and all the STEP files are included in the thrust test stand folder. I haven’t included smaller hardware like the M4 bolts or the microcontroller in the BOM, since I already have those components on hand.

At this stage, the test stand is focused on measuring and throttling thrust output. In the future, I plan to upgrade the setup to also measure and analyze the thrust vectoring capabilities of the high-pressure water rocket engine.

Also, for clarity and formal documentation, I used ChatGPT to help rephrase some sections of the writing.
